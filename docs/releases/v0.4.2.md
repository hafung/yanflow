# YanFlow v0.4.2

修复已写入文本框却仍弹出气泡的判断错误，并调整实时监听快捷键和气泡交互。

- RichEdit 的选区位置将换行计作一个字符，而读回文字返回 CRLF 两个字符。修复换行
  对齐与插入核验；已完成送入和已核验一致分别记录，避免把核验差异当成未写入并再次弹出全文。
- 气泡根据文字实际宽度调整尺寸，长文本换行，并限制最大宽高以保持在显示器工作区内。
  复制仍保留完整文字；复制成功后按钮变为“关闭”，点击收起气泡。新结果到来时重新显示“复制”。
- `Ctrl+Win+Shift` 按一次开启实时监听，再按一次关闭；`Ctrl+Win` 保留按住录音、松开结束。
  组合键支持不同按键顺序和左右键，避免重复触发；先按 Ctrl+Win 再补 Shift 时，将已有
  按住采集转为实时采集。旧默认额外快捷键迁移，自定义额外键保留。
- 增加不依赖麦克风的 RichEdit 换行回归、快捷键状态、已送入不弹气泡、复制关闭、
  新结果状态恢复与自适应尺寸验证。

本版本未改变声学模型或 CTC 解码；不宣称原始语音识别准确率已提高。“纠正并记住”可针对
已确认的 `note ZS` / `noZS → Node.js` 保存带上下文的术语别名，改善最后输出，不会训练模型。
持续提高识别率需要同一批真实录音和人工真值，比较术语命中、误改、延迟及内存，再评测
解码阶段热词增强或其他模型。具体用法见包内 `docs/text-correction.md`。

本机没有麦克风；自动验证使用固定文字、模拟状态和现成音频，未运行真人录音或物理快捷键回归。
GitHub ZIP 仍未签名，首次运行可能有 SmartScreen 提示。
