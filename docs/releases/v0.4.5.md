# YanFlow v0.4.5

录音时在输入光标旁预览识别文字，结束后再写入最终结果。

- 可定位的文本光标上方显示实时识别气泡，只保留识别内容。短句按文字长度调整宽度，
  长句自动换行，靠近屏幕顶部时改到光标下方；支持不同显示器的缩放比例。
- 气泡不抢焦点，鼠标可以穿透。按住模式松开后写入最终结果，实时监听在每段识别结束后写入；
  目标窗口或原生输入控件改变时，结果保留在备用气泡中。
- 临时识别使用可替换的音频快照，最终识别优先处理。长录音预览显示最近约 8 秒，
  最终识别仍处理完整录音。推理继续由独立 C++ worker 执行，采集回调保持固定环形缓冲写入。
- 录音和识别中的浮动图标增加柔和的呼吸光环，空闲时停止动画。
- 右键新增“隐藏浮动图标”，隐藏状态会保存；按 `Ctrl+Alt+H` 恢复。
  隐藏图标后仍可使用录音快捷键和光标旁预览。

已使用录音重放验证原生输入框与开启辅助功能的隔离 VS Code 窗口：识别期间显示临时结果，
结束后写入并关闭预览；原生输入框另核验了没有提前插入文字。已运行完整 Windows 构建和 UI 专项检查。
后续精简气泡文案仅重新编译，未重复端到端测试。未运行真人麦克风、物理快捷键或长时间运行验证；
记事本窗口验证未运行。应用需要提供可定位的输入光标才能显示光标旁预览。
