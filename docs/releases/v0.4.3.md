# YanFlow v0.4.3

将“编辑词典”改为可视化词库管理，并说明它与“纠正并记住”的使用场景。

- 右键“词库管理”可按通用、开发或应用范围查看、搜索、新增、修改和删除规则。
  已保存过的应用词库也可从范围列表选择；不再打开记事本编辑 TSV。
- 直接填写误识别词、正确词及可选同句上下文。“试一句”实时预览当前这条规则的替换结果，
  无需录音；例如 `note ZS → Node.js`，也可分别添加 `noZS` 等已确认的其他误识别形式。
- “纠正并记住”从最近结果添加规则，并复制本次正确文本；新增选中原始误词后填入的按钮，
  默认不再将整句话填入替换字段。保存的规则可以在词库管理中修改或删除。
- 首次保存保留包内模板，升级保留个人词库。保存校验规则，拒绝重复或冲突目标，
  保留旧文件中的注释和未修改的无效行，沿用文件锁及原子替换；文件损坏、不可写或已被
  其他窗口修改时保留原文件并提示，不会用旧列表覆盖新规则。
- 增加原生窗口控件回归：新增、修改、删除至空词库、搜索、上下文和代码保护预览、范围隔离、
  损坏 UTF-8、文件锁和过期写入保护；验证从原始识别选词记住的操作。

两个入口维护同一套精确规则，不训练模型，也不会自动推断新的误词。本次未改变声学模型
或解码器，不宣称原始识别准确率已提高。用法与 Node.js 示例见包内 `docs/text-correction.md`。

本机没有麦克风；验证使用固定文字与原生控件，未运行真人录音或物理快捷键回归。
GitHub ZIP 仍未签名，首次运行可能有 SmartScreen 提示。
