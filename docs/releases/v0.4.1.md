# YanFlow v0.4.1

修复中文在输入阶段损坏、MacBERT 资源漏打包及识别对照无法区分多次输出的问题，并缩小悬浮界面。

- 折叠图标改为 64 × 64，移除“大框套小框”的外层留白。转录气泡缩为 480 × 112，
  “复制／写入”改成一列 56 × 28 的按钮；写入仍保存到桌面 UTF-8 TXT。
- 标准 Unicode 文本框通过宽字符插入并核验实际新增文字；现代编辑器使用 Unicode
  剪贴板粘贴。只读、焦点不匹配或无法核验成功时保留气泡。粘贴路径会保留本次文字在剪贴板，
  并明确记录为未核验，不把键盘事件发送成功当成文字一致的证据。
- 每个标准构建与 Release ZIP 必须包含完整 MacBERT 模型、worker、运行时和许可证。
  模型仍默认关闭，开启后后台加载；菜单显示加载状态，并可查看具体失败原因。
- 最近识别对照保留本次运行最近 20 条，记录顺序、自动纠错、手工纠正、模型状态与
  输出核验情况。退出后清空内存，不保存录音或自动持久化历史。
- “纠正并记住”是可编辑、可限定应用与上下文的精确替换词库；它不会训练模型，也不会
  自动猜测新的误识别。MacBERT 只纠正受门槛约束的中文字符，不推断英文术语。

此版本的 GitHub ZIP 仍未使用受信任的代码签名，首次运行可能触发 SmartScreen。
核对官方 Release 来源和 SHA-256 后，确认信任下载的用户可选择“更多信息 → 仍要运行”；
组织策略可能不允许。受信任签名和下载信誉，或 Microsoft Store 分发，才是正式改善路径。
签名不能保证新版本立即免提示，详见
[微软说明](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)。

本地验证覆盖 Windows Release 构建、Unicode 中文／英文／emoji 输入、ANSI 消息循环宿主、
只读回退、复制／写入按钮、实际 MacBERT 调用和缺失／损坏模型诊断，以及 ZIP 解压启动。
本机没有麦克风；未进行真人录音回归，也未验证另一台电脑的实际输入场景。
